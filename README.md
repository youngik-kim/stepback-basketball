# 🏀 STEPBACK · 스텝백 승률 &amp; 스탯

일요일 농구팀 **스텝백(STEPBACK)** 의 누적 승률·개인 스탯·주간 경기 결과를 폰에서 보기 좋게 정리한 단일 HTML 페이지입니다.

- 🌐 **https://youngik-kim.github.io/stepback-basketball/**
- 🏟 구장: 시흥 SH스포츠센터 · 매주 일요일
- 📅 집계: 2026-01-03 ~ 2026-11-22 · 45회차(기록지 46장) · 3파전 34회 / 2파전 11회 · 총 135경기
- 🔒 **팀 입장 코드** 필요 (HTML 소스에는 데이터가 암호문으로만 들어갑니다)

## 화면 구성

0. **우측 상단 유튜브 배지** — `스텝백 STEPBACK` 제목 오른쪽에 농구공·`STEPBACK` 로고 배지 + `▶ YouTube 구독 ↗` 버튼이 있습니다. 링크는 구독 파라미터가 붙은 `https://www.youtube.com/@stepback_basketball?sub_confirmation=1` 입니다.
   - **안드로이드**: `intent://www.youtube.com/@stepback_basketball?sub_confirmation=1#Intent;scheme=https;package=com.google.android.youtube;…;S.browser_fallback_url=…;end` 로 유튜브 앱을 바로 엽니다(앱이 없거나 막힌 브라우저는 `browser_fallback_url`/1.5초 뒤 웹 구독 페이지로 대체).
   - **아이폰(iOS)**: `youtube://www.youtube.com/@stepback_basketball` 스킴으로 앱 호출을 시도하고, 700ms 뒤에도 페이지가 그대로면(`!document.hidden`) 구독 URL 로 넘어갑니다.
   - **PC·기타**: 기본 https 링크를 새 탭으로 엽니다. 390px 에서도 제목과 겹치지 않게 좌우 flex 배치·폰트 미세 조정.
0. **상단 요약 카드 4개** — `정규` / `경기` / `게스트` / `최고 승률`. 탭하면 각각 최종 승률 섹션 · 주간 결과 전체 · 게스트 명단(자동 펼침) · 1위 선수 개인 카드로 이동합니다(고정 바에 가리지 않게 `scroll-margin-top` 보정).
1. **주차 선택 바(상단 고정)** — `‹` / 날짜 드롭다운(45회차) / `›` / `최신`. 과거 날짜를 고르면 그 회차 경기 결과와 **그 회차까지의 누적 승률·순위·게스트**로 화면 전체가 바뀝니다.
2. **경기 결과** — 팀 성적(승·무·패, 득실)·스코어·팀 명단(게스트는 `G`)·특이사항. 2026-02-15처럼 기록지가 2장인 날은 기록지별로 나눠 보여줍니다.
3. **최종 승률** — 정규(참여율 40%↑ 18회 이상) 16명 · 순위 외 4명 · 시즌 하이라이트 · 게스트 71명(출전 순)
3. **최종 승률** — 정규(참여율 40%↑ 18회 이상) 16명 · 순위 외 4명(준회원 2명 포함) · 시즌 하이라이트 · 게스트 71명(출전 순). 준회원(강종은·김태원·박지수)은 이름 옆 `준회원` 배지로 구분합니다.
4. **개인 스탯** — `시즌 누적` / `시즌 누적(쿼터당)` / `직전 경기`(날짜 드롭다운 **5회차: 26.11.22 · 11.15 · 11.08 · 11.01 · 10.25(3G)** + `총합|쿼터당` 보조 토글). 기록지 전 항목 15열: **선수 · 득점 · 리바(ORB+DRB) · ORB · DRB · 어시 · 스틸 · 블락 · 턴오버 · 파울 · 2점 · 3점 · 자유투 · MVP · 출전**. MVP 포인트 열이 없는 26.11.01 · 10.25 기록지는 `–` 로 표시합니다.
   - `쿼터당` 모드는 득점·리바·ORB·DRB·어시·스틸·블락·턴오버·파울을 각 선수 **출전수(gp)** 로 나눈 평균(소수점 1자리)으로 표시하고, 정렬도 그 수치 기준입니다. 2점·3점·자유투는 성공률(%) + 쿼터당 성공/시도.
   - 왼쪽 `선수` 열은 **고정(sticky)** 되고 표만 **좌우로 스크롤**됩니다 — 폰(390px)에서 페이지가 흔들리지 않고 15개 열을 모두 볼 수 있습니다.
   - 상단 정렬 칩(11종)과 **표 헤더 클릭**(14개 열 전부)으로 정렬. 2점·3점·자유투는 성공률(%) 기준, 동률은 성공 개수 → 시도 수 순. 정렬 칩을 누르면 그 열이 왼쪽 `선수` 고정 열 바로 옆에 오도록 표가 **부드럽게 자동 가로 스크롤**됩니다(예: `턴오버` → 오른쪽으로 이동).
5. **로스터** — 총 21명(정회원 18 · 준회원 3) 백넘버·신장·포지션(복수 포지션은 앞 포지션 기준 필터, 신장순·`준회원` 필터)
6. **주간 결과 전체** — 최신 회차부터 45개 아코디언

선수 이름을 누르면 개인 카드가 뜹니다 — 승률·승무패·참여율·신장·포지션·백넘버·정회원/준회원/게스트 배지, `시즌 누적` / `시즌 누적(쿼터당)` / `직전 경기` 3모드 스탯(총합 모드엔 `평균(점/Q)` 카드 포함, `직전 경기`는 카드 안에서도 5회차 날짜 선택 + `총합|쿼터당`), 회차별 상대/스코어, 2파전·3파전 분리 전적.

## 개인 상세정보(키·넘버·포지션) 입력·업데이트 + 카톡 복사

개인 카드에서 **정회원 18명·준회원 3명**이 자기 키·넘버·포지션을 직접 채우고, 스텝백 카톡방에 보낼 양식을 바로 복사할 수 있습니다. **게스트는 대상이 아닙니다**(폼·버튼 자체가 없음).

- 카드 상단 배지에 `#24 · 181cm · SF/PF` 처럼 표시되고, **로스터 카드·개인 스탯 표의 메타도 같은 값**으로 즉시 바뀝니다.
- 정보가 다 있는 회원은 **`개인정보 업데이트하기`** 버튼 → 폼이 열립니다. 키·포지션이 비어 있는 신규/누락 회원은 폼이 **자동으로 펼쳐지고**(`개인 상세정보를 입력해 주세요`) **`다음에 하기`** 로 접을 수 있습니다.
- **넘버 `-`(없음) 처리**: 로스터에 넘버가 `-` 이고 키·포지션이 있는 회원(`이준평`·`이진세`)은 **`번호없음`으로 확정**으로 봅니다 — 배지는 `번호없음 · 172cm · SG`, 버튼은 `개인정보 업데이트하기`, 폼을 열면 `없음` 체크가 이미 켜져 있고 넘버 입력은 비활성입니다.
- 폼: 이름(고정) · 키(cm, 120~230) · 넘버(0~99 + `없음` 토글) · 포지션(`PG / SG / SF / PF / C` 복수 선택).
- **`저장 및 카톡 복사`** → `localStorage`(`stepback-profile-v1`)에 이 기기 한정으로 저장되고, 아래 양식이 클립보드에 복사되며 수동 복사용 텍스트 박스도 함께 표시됩니다(인앱 브라우저 대비).
  ```
  스텝백 정보 업데이트 요청 드립니다.
  [김영익 / 181cm / 24번 / SF/PF]
  ```
  (넘버 없음이면 `없음`)
- 폼과 복사 영역 모두에 `※ 입력 내용은 현재 기기에만 임시 적용됩니다. 복사된 양식을 스텝백 카톡방(관리자)에 전달해 주셔야 전체 페이지에 최종 반영됩니다.` 안내가 있습니다.
- 기기 저장값은 로스터 값보다 우선하며, 브라우저 저장소를 지우면 로스터 값으로 돌아갑니다.

## 매주 갱신 방법

```bash
# 1) 기록지 내용을 basketball/stepback-records.md · stepback-guests.md ·
#    개인 스탯표(basketball/2026-11-22-스텝백-개인스탯.md, basketball/2026-10-25~11-15-스텝백-개인스탯.md)에 반영한 뒤
python3 src/build_data.py      # -> src/data.json (평문, 커밋 금지) + 기록지 표와 자동 대조 검증
python3 src/build_site.py      # -> index.html (ENC_DATA 암호화) + robots.txt
LD_LIBRARY_PATH="$(cat ../.libs/ldpath.txt)" python3 src/verify.py   # (선택) 390×844 / 1280×800 렌더링·기능 검증
```

- `build_data.py` 는 주차별 로스터×팀 성적에서 개인 승·무·패·출전·2파전/3파전을 **다시 계산해 기록지 표와 대조**합니다. 불일치가 있으면 목록을 출력하고 종료코드 1로 끝납니다.
- 입장 코드는 `site/.entry-code` 파일(또는 `--code`, `STEPBACK_ENTRY_CODE`)로 넣습니다.

## 보안

- `index.html` 에는 `<meta name="robots" content="noindex, nofollow">`, `robots.txt` 는 `User-agent: * / Disallow: /`.
- 데이터는 **PBKDF2-SHA256 20만 회 → AES-256-GCM** 으로 암호화해 `const ENC = {…}` 로만 내장됩니다. HTML 소스에 선수 이름·전적·입장 코드가 평문으로 남지 않습니다(빌드 시 자동 검사).
- 입장한 기기는 `localStorage` 에 **복호화 키만** 저장해 재입장을 생략합니다. 푸터 `🔒 잠금` 버튼으로 즉시 잠글 수 있습니다(공용 PC).
- **절대 저장소에 올리면 안 되는 파일**: `src/data.json`(평문 명단), `.entry-code`. `.gitignore` 에 포함되어 있습니다.
- 배포물은 `index.html` · `robots.txt` · `.nojekyll` 뿐입니다.
